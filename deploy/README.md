# deploy

存放可版本管理的部署配置和操作说明；当前没有部署脚本或运行环境。

| 环境 | 标识 | 后续对应代码 |
| --- | --- | --- |
| 个人开发与共享联调 | `development` | 个人任务分支或 `develop` |
| 发布验收 | `staging` | 当前 `release/*` |
| 正式服务 | `production` | `main` 上选定的正式标签 |

选定部署平台后，在此补充构建、配置注入、数据库迁移、健康检查、备份和回退步骤。三个环境的数据库、用户数据和凭据应隔离。

正式版本记录标签、源码提交和构建产物标识，部署已验证的同一份产物。真实密钥保存在部署平台或本地未跟踪文件中，不写入配置模板。
