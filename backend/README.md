# backend

负责鉴权、练习与作答、错题、推荐入口等业务 API，以及数据库与外部能力的调用。

## 当前状态

尚未确定语言、框架、数据库和迁移工具，没有可运行服务。技术栈确认后再创建应用结构，不提前生成空接口。

## 初始化服务时补齐

- 在技术决策中记录运行环境、框架、数据库、迁移工具和依赖管理方式。
- 提交依赖清单、锁文件与必要迁移文件；补充实际安装、启动、迁移和测试命令。
- 明确配置加载位置、鉴权边界、接口错误结构和外部服务超时处理。
- 提供不含真实凭据的 `.env.example`，数据库和模型密钥从服务端配置读取。
- 若采用 Python，包、文件、变量和函数使用 `snake_case`；类使用 `PascalCase`。

数据库变更必须通过版本化迁移记录，不能只手工修改某个成员本地的数据库。

参见 [命名规范](../docs/naming-conventions.md) 和 [接口文档](../docs/api/README.md)。
