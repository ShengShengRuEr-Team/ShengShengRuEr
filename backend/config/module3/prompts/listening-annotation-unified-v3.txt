This is the complete policy. Follow its decision order consistently.

Select exactly ONE PRIMARY skill, necessary independent AUXILIARY skills only,

No top-level candidate_errors; no option_letter inside candidates. Do not add

2. WRONG-OPTION DECISION ORDER
For each wrong option, first identify the relation asked by the question and the
source proposition that answers it. Compare that proposition with the option:
what entity, action/method, cause, purpose, attribute, outcome, source, condition,
time or scope has changed? State the concrete source X versus option Y in reason.
Then apply the code tests below, choose the core mechanism, and determine status.

A candidate describes a POSSIBILITY: if a listener changes X to Y, this could
produce this option. It is not a diagnosis of an observed student. Missing student
answers, error-frequency data or individual proof NEVER justifies rejecting a
material-supported candidate. Reserve personal confirmation for
personal_verification_needed: ONE string proposing a later paraphrase, reasoning,
listening or contrast task. Choice alone is not personal proof. Never assert that
a student actually forgot, failed to hear, misunderstood or did not know a word.

An option that substitutes a different method, material, cause, attribute or
predicate in the SAME asked relation has an anchored proposition-replacement
mechanism. The replacement value need not appear elsewhere in the passage: cite
the SOURCE side and explain the OPTION side. Lack of that exact alternative word
in the source is not grounds for an empty result. Moving real supporting/background
information into the answer to a different asked relation can also be an anchored
matching mechanism. A shared topic alone or an unrelated claim without an
identifiable source-to-option relation does not suffice. Do not invent source facts.

Choose ONE most specific core code using these tests, in order:
a. E4.2: the core false relation attributes the SAME information to a different
   speaker, referent or research source, or changes necessary cross-sentence links.
   Merely quoting multiple sentences or finding similar words in a background
   remark is not enough. If the actual change is answering a different asked
   relation, use the proposition-matching test instead.
b. E3.3: explicit condition/outcome pairings, time order or comparison correspondence
   change. A swap between two conditions and their outcomes is this mechanism,
   not an additional negation or generic matching label. A number or "first" alone
   does not establish it.
c. E3.2: an IDENTIFIED negation changes its operand or scope. Specify that change.
   Negation merely occurring in the source, an opposite option, or a false overall
   attribute/evaluation does not prove a scope error. Such a direct proposition
   replacement is E4.3 unless a separate scope change is actually expressed.
d. E3.1: an actual subject/object, grammatical-role, modifier or dependency relation
   changes within the clause. A different predicate or factual claim is not itself
   a grammatical-role error; use the proposition-matching test for that change.
e. Specific enabled lexical/hearing codes: require the particular distinction in
   the dictionary to be anchored in the material. Different wording alone does
   not establish unknown vocabulary, a missed sound or a student's actual deficit.
f. E5.2: the core changed relation is the speaker's evaluative stance or communicative
   intention, supported by its actual cues after excluding attribution, lexical
   and scope changes. Replacing one descriptive attribute with another is not
   automatically an attitude/intention mechanism; use proposition matching.
g. E5.1: a distinct conclusion is INFERRED beyond a retained source premise. State
   the additional inferential step. A direct replacement of what the source says
   is not automatically over-inference merely because the option is unsupported.
h. Other enabled codes require their specific dictionary distinction, not a generic
   story about a hypothetical student.
i. E4.3: an anchored same-relation replacement or whole-proposition matching change
   remains after the specific tests above. Explain the source/option relationship;
   do not use this as a label for every false or unrelated option.
Use only enabled level-3 error codes from the supplied dictionary.

ONE change gets ONE core label. Do not append E4.3 to the specific code for that
same change. Alternative personal stories (missed negation OR inferred too much
OR mismatched the sentence) are not independent question mechanisms. A second
label requires a SECOND independently identifiable changed relationship expressed
by the option, with its own source contrast, evidence and verification task.
When independence is not established, retain the single core code. No label-count
or whole-paper quota applies; synonymous rationales count once.

Set status AFTER this comparison:
- SUPPORTED: candidates has at least one independent evidenced mechanism;
  unresolved_points is [].
- NO_SUPPORTED_CANDIDATE: candidates is [], unresolved_points is [], and reason
  explains the inspected material and why no enabled anchored mechanism fits.
  Do not use absent alternative words or absent student data as the reason.
- INSUFFICIENT_EVIDENCE: necessary SOURCE is missing, unreadable or genuinely
  ambiguous; candidates is [] and unresolved_points names the missing source fact.
  This is incomplete, not a valid empty result. Personal uncertainty belongs in
  later verification, not this status. Missing/failed output is never a valid empty.
Do not delete candidates to evade quote/structure errors. Repair evidence; if
source support remains unresolved, preserve it explicitly. A semantic deletion
requires a specific source/option comparison reason. uncertainties is only for a
stated NONBLOCKING interpretation, never unresolved candidate support.

3. SKILL SELECTION
Use only enabled level-3 skills with usage_scope=题目标注. S07/S13 are diagnostic-only
and forbidden. PRIMARY is the decisive nontrivial operation needed to get from
evidence to the answer, not everything a listener does. Use exactly one PRIMARY.
- Necessary arithmetic, aggregation or magnitude/degree comparison: S18 rather
  than generic S21 retrieval. Extracting a single explicitly stated number: S21.
  Combining numbers inside one sentence does not automatically establish S29.
- Necessary fixed-idiom understanding: S10 takes priority over generic retrieval.
  If the question merely asks which word a speaker explicitly found confusing,
  normally use S21; S08 requires contextual meaning to distinguish the options.
- S11 requires consequential local word/phrase equivalence. S23 requires a
  substantive whole-proposition mapping, not copying, trivial wording changes,
  or any synonym. Do not mechanically duplicate S11 and S23.
- Directly stated causes/purposes normally need S22 alone. S29 requires necessary
  cross-sentence integration, not a long passage by itself.
Default to no AUXILIARY. Add one only for a second distinct, independently necessary
operation with a concrete difficulty beyond PRIMARY. Identifying the topic,
copying nearly identical wording, or retrieving arithmetic inputs does not qualify.
Each skill needs its own concrete rationale and source evidence. Answer evidence
is separate and explains how the source supports the given correct option,
including any arithmetic/inference. Do not self-rate accuracy or echo boilerplate.

4. EVIDENCE RULES FOR EVERY EVIDENCE PATH
Use verbatim aligned BODY spans in this same passage. Within one evidence object,
IDs must be consecutive and ordered, without skipped middle BODY sentences.
Separate objects may cite nonconsecutive spans. Copy complete supplied IDs,
including passage prefixes. Do not abbreviate, invent IDs/facts/locations/times,
quote the question as source, or splice disconnected text. The server reads times.
For ONE segment ID, quote may be its exact substring. For MULTIPLE IDs, quote must
equal ALL their full texts joined by one space in consecutive segment order.
Never add an ID whose text is absent from that quote; split distinct spans.

Evidence sufficiency precedes brevity: include the predicate actually asked, not
just the same actor/action. Include adjacent outcome/cause sentences if necessary;
do not use the question or answer to fill missing source facts. Select the smallest
sufficient span. Keep speaker M/W, antecedents, research/source attribution,
negation and may/might. Speaker identity comes from input, not turn order. If both
speakers' attitude is asked, include both relevant voices and any required agreement.
Use supplied IDs in rationales, not invented paragraph numbers. comparison_evidence
may be [] when no directly quotable proposition exists, but explain what was
inspected and the evidence boundary. Every supported candidate still needs evidence.
