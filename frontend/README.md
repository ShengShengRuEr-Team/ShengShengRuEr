# frontend

负责学习者使用的界面、听力播放与交互，以及调用业务 API 的适配层。

## 当前状态

尚未选择框架、包管理器和 UI 组件库，没有可运行应用。不要在此基础上假定 React、Vue 或任何其他框架已经确定。

## 初始化应用时补齐

- 在技术决策中记录框架、运行环境版本和包管理器。
- 提交应用入口、依赖清单及锁文件，补充实际安装、启动、构建和必要测试命令。
- 在模块根目录提供 `.env.example`，说明可以打包进浏览器的公开配置。
- 页面和组件使用 `PascalCase`，普通模块使用 `kebab-case`，代码变量使用 `camelCase`。
- 与后端先约定接口；JSON 字段保持 `snake_case`，在请求适配层转换。

模型密钥、数据库密码和对象存储私钥只保存在服务端，不能放进前端环境变量。

参见 [命名规范](../docs/naming-conventions.md) 和 [接口文档](../docs/api/README.md)。
