# ai

用于版本管理错因分析、推荐、提示词、模型配置约定与评测材料。

## 边界

此目录是 AI 能力的代码与资源边界，不意味着已经决定部署独立 AI 微服务。初期如何由后端调用、使用何种语言和依赖方式，选型后写入技术决策。

- [prompts](prompts/README.md)：提示词、输入输出要求与变更说明。
- [evals](evals/README.md)：评测方法、小型脱敏样例与结果记录约定。

外部模型密钥仅通过服务端环境配置注入；完整题库、模型权重、用户输入和录音不放入 Git。服务端的权限校验、接口格式和持久化由后端统一协调。

改变提示词、模型或推荐规则时，记录变更理由并运行相关评测，不能只以一条演示结果判断效果。
