## 提示词与范围

试验补充规则位于 `backend/config/module3/prompts/option-consistency-v1.txt`，追加到原 V7 系统提示词。实验提示词版本为 `m3.annotations.v7.consistency-v1`，使用受控目录中的代码副本运行，应用默认 V7 提示词不变。生成规则、来源、模型参数、每题最多两次纠错、费用账本及编辑头隔离继续执行。

补充规则的主要含义：

1. 先比较题目询问的关系、错误选项命题及原文命题，再判断是否存在具体、可引用的理解变化。不能因为没有学生作答或缺少错误发生频率，就拒绝题目层面的候选机制。
2. “无支持候选”要求具体说明原文到选项的机制边界；“依据不足”用于缺失、模糊或无法读取的必要来源，不用于缺少学生数据。后续个人核验单独记录。
3. 区分类别：来源/指代归属用 E4.2；条件、时序或比较对应用 E3.3；真实否定范围变化用 E3.2；句内语法角色变化用 E3.1。E5.1 要明确增加了什么推断；E4.3 用于没有被更具体机制解释的整体命题对应变化。
4. 同一理解变化选最具体的标签，不将其同时改称为否定、条件和笼统匹配三个错因。多个标签仍须独立机制、证据及核验依据。不能以统一输出或空标签作为目标。
5. 补充独立的合成边界例子，不将本次试卷的题号、模型原标签或目标相同率发送给模型。
