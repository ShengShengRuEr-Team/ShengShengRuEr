## 本轮实现

1. 接通同一管理员 API、登录与题库入口，增加处理列表、新建和任务详情、只读逐题审核及正式标注回读。学生 DTO 不新增错因。
2. `0007_m3_attempt_merge` 合流历史，`0008_m3_continuation` 建立工作流/修订/命令/审核，`0009_m3_error_invariants` 增加版本门控、逐题生成状态、实际批次身份映射和延迟关系约束。保留历史空选项，不将旧标签冒充新规则。
3. 持久化命令按原键回放后再检查业务版本。同键异请求、过期新请求及跨管理员查询被拒绝；页面发送前保存原键与原请求，丢响应可查询或恢复。
4. 三类原件先预留再传输：流式大小/哈希、真实 PDF/音频解码检查、上传版本、进度租约、取消、晚到写回 fencing、原子内容发布和失效暂存清理。冻结后替换原件必须建立材料子修订。
5. 独立 Worker 执行对齐、来源、5题试标、整套生成，最终停在审核。核听/来源/小样审批与继续分开；GET 不推进。停止撤销令牌，监督进程只终止所属子进程树；失效执行不自动再次付费发送。
6. 新错因必须绑定具体基准错误选项并有理由与证据，排除正确选项，支持合法空结果和一选项多编码。同一身份去重保留有效证据，实质冲突阻断。数据库约束父子归属、批次/同篇正文、生成/审核身份及最后一条证据。
7. 每题保留实际调用、响应、不可变候选和 receipt；最终发布前重建并比较候选关系。账本跨任务/同原音累计，发送前检查租约，未知计费不清零。新版内容哈希不依赖已登记材料的自增 ID。
8. 审核页不编辑内容；逐题保存意见/退回，完整覆盖技能、答案证据及每条错因/证据，空错因需明确确认。最终核听须填写实际依据；批准后会话不可改写，新最终结果创建空审核会话。
9. 受控来源校正按白名单、原值/父哈希、实际原件页码及定位建立子修订，保存前后值和操作者，禁止修改模型标签/理由/证据。原文/对齐工具只提供来源句及搜索范围，重新计算边界，不接受手填已对齐时间。
10. 局部修复先预览依赖范围和 plan_hash，再按原计划执行。第12题独立变化可复用实际小样审批引用；前5题/共享依赖/方法变化重做试标。祖先 receipt 仅在依赖和方法校验后复用，最终始终整套重审。
11. 发布先提交非当前 pending 批次，再核对实际题目、关系、字典编码、原件定位、证据句序及逐题生成身份，通过后原子切换当前批次/音频。新批次默认隐藏；独立开放/撤销携带 expected_batch_id。
12. 正式详情只读取当前批次有效标注；旧错因或过期方法显示待重新标注，保留旧卷有效开放。证据片段按原音哈希、绝对时间及转换版本私有缓存，媒体入口鉴权。

操作及恢复方式见 [统一管理端操作说明](continuation-runbook.md)。
