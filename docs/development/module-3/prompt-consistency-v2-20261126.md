# 错因提示词 V2 定向复测

日期：2026-11-26（Asia/Shanghai）。本轮来自用户对上一轮差异的三项明确决定：具体做法/属性替换是否构成可能错因，以 DeepSeek 的判断方式为准；同一偏差是否多标签，也采用 DeepSeek 的核心单标签方式；单纯引文精确匹配不合格，本轮不再专项处理。

## 提示词修改

新补充规则为 `backend/config/module3/prompts/option-consistency-v2.txt`。在独立代码快照中仅追加该 V2 补充，不叠加 V1；提示词版本为 `m3.annotations.v7.consistency-v2`。原输出结构、来源、词典和模型参数保留。

规则的中文含义：

1. 比较题目所问的语义位置，例如“谁做了什么”“用什么方法”“什么原因”“什么属性”，再比较原文命题与错误选项命题。
2. 选项在同一语义位置替换原文中的材料、方法、属性、原因或谓词，本身可以构成有依据的含义匹配偏差。证据引用原文一侧，错误替换来自选项，不要求错误选项中的替代词也出现在原文中；不能因为未观察到学生行为就拒绝候选。
3. 同一变化默认选一个核心标签。不要将“可能没处理否定”“可能过度推断”“可能整体匹配错误”三种个人路径同时写成三个题目机制。
4. 否定标签要求真实的作用范围或作用对象变化，不能仅因原文有 not 或选项意思相反就添加。若选项只是整体评价/属性替换且没有独立表达的否定范围变化，用 E4.3 核心标签即可。
5. 来源归属 E4.2 要求错误命题的核心确实将同一信息归给另一来源；从另一说话人的背景话语取词，并不自动等于来源混淆。条件/时序对应交换用 E3.3；真实语法角色变化用 E3.1；额外推断结论才用 E5.1。
6. 多标签仍允许，但第二标签须对应选项中第二个独立改变的关系，有自己的证据、比较和核验；同一变化的不同解释不能重复贴码。

不将原试卷的题号、原模型标签清单、目标相同率或另一模型回答发送给模型。DeepSeek 的判断边界是用户选择的标注政策，不据此声称其所有历史输出都是真实语义标准答案；两家仍各自独立生成新结果。

## 范围与比较口径

只重跑原整卷报告中存在差异的16题：1、2、5、8、9、11、12、13、14、15、17、20、21、22、23、24。每题两家各自生成全部三个错误选项，共48个比较单位；其中原严格口径不一致的31项另作子集观察。未重跑题目不混入本轮结果。

主报告“仅标签相同率”比较相同错误选项的完整编码集合，仍验证来源/题目身份、AI来源、词典绑定、选项集合、状态与结构、合法编码及重复编码；只省略引文逐字定位与连续片段匹配这一层。依据不足、非法编码、重复/缺失选项不能变成合法空集合。另保留原严格比较报告，不能将“标签相同”声称为“引用通过”或正式准入。

本轮不因单纯引文错误提前停止其他题目，不反复自动搜索提示词。每题原有最多两次有限纠错、真实费用账本、执行权和隔离编辑头继续执行；配置、供应商或执行权全局故障仍停止。全轮只运行这一个冻结提示词版本。
