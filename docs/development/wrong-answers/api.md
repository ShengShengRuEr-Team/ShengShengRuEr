# 错题本 API

接口前缀为 `/api/v1/wrong-answers`。所有请求均需学生 Bearer token。未登录返回
401，非学生返回 403。详情、音频和移除接口对不属于当前学生的记录统一返回 404。

| 方法 | 路径（相对前缀） | 行为 |
| --- | --- | --- |
| GET | 空 | 返回 `data.items` 和 `data.total`。支持 `page`、`limit`（默认 20，最大 100）和 `keyword`（最多 100 字符）。关键字匹配题干、考试级别、试卷编号。按提交时间倒序，同次按题号升序。 |
| GET | `/{attempt_code}/{question_no}` | 返回当次题干、选项、所选字母、正确字母、解析、现存听力原文及音频入口、技能、按选项匹配的候选错因和依据。 |
| GET | `/{attempt_code}/{question_no}/audio` | 返回作答批次对应的音频文件，支持 Range。音频缺失时返回 404。 |
| DELETE | `/{attempt_code}/{question_no}` | 移出本人错题本并返回 200。重复请求返回相同结果。原作答和成绩保留。 |

每条错题对应一次成功提交中的一题。查询直接读取已保存的判分快照，因此包含上线前的作答。
未作答沿用现有判分规则计错并显示「未作答」。同题多次作答按各自记录呈现。
移除后该条详情及音频入口返回 404。

答案、选项和解析取自提交快照。听力材料和标注限定在该次作答的题目和批次，试卷换批后
仍按原批次复习。素材缺失时详情仍可返回。候选错因须通过当前错因规则版本及作答批次的
标注审核绑定校验，并按原卷选项映射至题库选项。现有项目无个人错因确认记录，
`personal_cause_status` 返回 `unconfirmed`。
