# 接口约定与导航

当前已实现模块一认证接口和模块二听力试卷接口。

| 范围 | 契约入口 |
| --- | --- |
| 模块一：登录、退出、当前用户与管理员概览 | [后端说明](../../backend/README.md) |
| 模块二：列表、详情、音频、管理员配套内容、可见性与检查 | [听力试卷接口](module-2/api.md) |

统一使用 `/api/v1` 前缀，字段用 `snake_case`，响应外壳为 `code`、`msg`、`data`。鉴权先判断 401，再判断 403；模块二隐藏试卷对学生统一返回 404。管理员配套查询使用管理员接口。

运行中的 OpenAPI 位于 `/api/v1/openapi.json`，Swagger 位于 `/docs`。接口改动同步更新模块契约，写清角色范围、请求字段、响应、失败条件及兼容性。
