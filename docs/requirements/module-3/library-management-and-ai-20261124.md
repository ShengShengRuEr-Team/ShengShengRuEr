## 一 需求优先级与范围

本文件补充[模块三原需求](requirements.md)、[续开发需求](continuation-20261115.md)和[模块二需求](../module-2/requirements.md)。本轮用户确认的变更优先适用，历史文档和验收结论保留原有范围，不追溯改写。

| 原要求 | 本轮要求 |
| --- | --- |
| 音频对齐后独立核听确认，再组装题目 | 对齐后继续组装，核听与来源内容审核合并，确认后才能启动标注 |
| 前 5 题试标并人工确认，再标注整套 | 取消试标及对应批准依赖，一次启动整套标注 |
| 审核页只审核和退回 | 在现有页面增加显式编辑入口，支持人工修改内容、技能、错因和证据 |
| 固定使用 DeepSeek | 默认 DeepSeek 官方，新增阿里云百炼官方千问作为替代 |
| 仅退回重生成或后台来源校正 | 保留原能力，增加管理端编辑、版本记录、差异查看和回退 |

### 本轮交付范围

- 沿用现有登录、管理员权限、React 与 Ant Design 界面、路由、Worker、版本化入库和独立开放机制。
- 支持试卷与草稿内篇章、题目的增删改查，提供回收站。
- 支持人工修改标注、来源内容与证据，记录每次有效保存。
- 支持历史版本保护、七天保留、回退与依赖校验。
- 默认使用 DeepSeek 官方 `deepseek-flash`，替代使用阿里云百炼官方 `qwen3.8-flash`。
- 提供一套 25 题的双模型对比结果及分歧清单。

### 本轮边界

不新增独立工作台、不改变学生端错因隔离、不增加个人错因自动诊断。无原文时仍须显式选择 ASR，不能静默替换原文路线。回收站不提供永久物理删除按钮。不以多套大规模评测、第三家模型、自动择优路由或自动模型降级作为本轮必需交付。

本轮仅交付四级、六级标准完整真题的管理、处理与发布。非标准练习卷、自编卷及其身份、判分和作答次数规则另立需求，不作为本轮新增、发布或验收对象。身份校正沿用受控后台工具或校正文件，本轮不新增身份校正管理页面。

## 二 现有基础与接入原则

当前试卷具有跨批次稳定身份，题目、篇章、原文和关系按批次保存，学生作答关联具体试卷和批次。保留这一结构，将管理操作接入现有题库，不另建一份可独立生效的题目库。

| 对象 | 含义与要求 |
| --- | --- |
| 试卷身份 | 同一考试等级、年月和套次的稳定业务对象；归档、恢复、更新不改变同卷身份 |
| 编辑草稿 | 尚未生效的内容，可多次保存；必需字段不完整时可以暂存，但不能送审或发布 |
| 保存版本 | 一次明确保存形成的内容快照，包含修改原因、前后版本和内容哈希 |
| 审核结果版本 | 审核所绑定的完整内容与标注结果；修改后形成新版本并重新审核 |
| 正式批次 | 已入库的内容版本；同卷仅一个当前批次，新批次失败不破坏旧批次 |
| 学生开放状态 | 与入库、审核分别记录；新批次不能继承一次旧开放确认而自动对学生开放 |

“最新保存版本”和“当前正式批次”是两个不同概念。编辑、回退或保存成功不等于正式题库已切换。

同一试卷只保留一个当前可编辑草稿，多管理员和多标签页共同受当前版本校验约束，不各自建立并行编辑草稿。历史修订和双模型评测结果可以独立留存；评测候选不自动成为当前编辑版本，管理员选定后才进入当前编辑修订。采用其他候选时仍检查当前版本、人工修改和关联依赖。

## 三 处理与审核流程

### 自动处理主流程

材料上传 → 文本提取或 OCR → 原文分句与音频对齐 → 组装题目 → 来源内容审核与核听 → 整套 AI 标注 → 本地校验 → 整套标注与内容审核 → 正式入库并激活 → 独立确认学生可见。

本轮沿用现有激活与独立开放机制：新修订待审核、待激活或入库失败时，旧当前批次及其有效开放状态保持不变；成功激活新批次后，旧批次不再是当前批次，新批次默认不可见。允许激活后至独立开放前该卷暂时不可供学生访问或新提交，页面须明确提示这一影响。旧批次数据和已有作答快照继续保留，不承诺在新批次未开放期间回退读取旧卷。未变化的幂等重复激活不得无故清除已有开放确认。

1. 取消独立的“对齐后人工确认”停点。自动对齐完成后，结构满足要求时继续组装题目。
2. 来源审核同时展示原件、题目、原文与音频，记录真实核听结果和来源核对结论。必需来源缺失、对齐异常未处理或核听未完成时，不能进入标注。
3. 取消 `annotate_sample`、前 5 题审核和小样批准对新流程的强制依赖。阶段流转、恢复、局部修复、预算分组和页面文案须同步调整，不能只隐藏按钮。
4. 来源审核通过后，一次启动整套标注。内部逐题调用、保存检查点与结果；无需中途人工批准，也不要求把整套内容合并成单次模型请求。
5. 每题失败保留已有结果、原始响应、失败原因和费用。重试仅针对明确选择且依赖有效的范围，不能默认重跑整卷。
6. 本地校验仍检查结构、编码、选项归属、引文、同篇正文及音频对齐依赖。校验通过不自动表示语义正确。
7. 最终审核覆盖整套题目、技能、答案证据、三个干扰项评估和错因证据。来源核听记录在原文、分句、音频及对齐依赖未变时可以引用；发生依赖变化时重新核听相应范围。整套最终审核须确认引用记录仍有效，不能凭空补写“已核听”。
8. 任一题内容、标注或证据变化后，整套最终审核结论失效；有效来源记录和未变化产物可按依赖复用，但不自动继承逐题最终通过结论。

### 人工新增与修改流程

新建或创建编辑修订 → 填写内容并保存版本 → 来源及结构检查 → 人工标注或 AI 辅助标注 → 整套审核 → 入库并激活 → 独立开放。

允许纯人工录入和人工标注，记录真实来源及实际操作人，不伪造模型调用。人工录入不能替代自动链路验收。只修改标签时不要求重新调用模型；只保存审核意见不产生内容版本，也不产生模型费用。

## 四 题库增删改查

### 新增试卷与题目

- 在现有题库列表增加“新增试卷”入口，支持上传材料自动处理及人工建立草稿。
- 填写考试等级、年份、月份、套次、题量及来源。重复试卷身份须提示进入已有试卷创建修订，不能通过重复新建绕过同卷限次。
- 草稿内可新增篇章、原文句子和题目，并关联音频与来源。题目填写题号、篇章、题干、四个选项、正确答案和解析。
- 题号重复、归属缺失、来源不足、答案不在 A—D 或题量不完整时，允许以缺项草稿保存并明确提示；送审和正式发布须满足完整性要求。
- 标准完整真题的应有题量按可信来源确定，不能因手工删题自动调小题量来通过检查。非标准练习卷不在本轮交付范围，不得通过改名或修改题量冒用标准真题及其判分与满分规则。

### 查询与详情

- 管理端按四级或六级、年份、月份、套次、处理状态、审核状态、开放状态及归档状态筛选。
- 支持按试卷编码、名称和题干关键词搜索，服务端分页；筛选条件和页码可在返回列表时恢复。
- 列表一次返回所需状态摘要、题量、当前批次及最新修改时间，避免依靠逐卷补查展示关键状态。
- 详情沿用现有入口，组织题目与标注、原件与音频、版本记录区域。显示题目对应的基准选项和展示选项，避免重排后错挂标签。
- 页面分别显示当前编辑版本、当前正式批次、审核状态、开放状态与归档状态，不能用一个“完成”状态混合表示。
- 学生查询继续遵循当前批次、内容检查与开放权限，不返回管理端答案、原文、错因或修改历史。

### 修改内容

- 已发布试卷通过“编辑”创建修订，不直接覆盖正式批次；待审核或已退回内容进入现有编辑区域处理。
- 支持修改题干、选项、来源答案、解析、原文及说话人信息；来源识别校正须保留原件页码、定位与修改理由。
- 音频内容、原文分句或对齐搜索范围变化时重新对齐相应依赖。证据时间由有效对齐片段派生，本轮不提供绕过对齐的任意时间戳覆盖。
- 更换正确答案、调整选项内容或顺序时重新校验映射、正确选项排除与全部关联标签，不能只改字母而保留旧关系。
- 草稿中支持删除题目或篇章，删除篇章时展示受影响的题目、句子和证据；不得留下悬空引用。正式卷的题目删除通过新修订生效。
- 发布版本的考试身份不允许普通编辑直接改成另一套试卷；来源登记错误沿用已鉴权管理员的受控后台工具或校正文件处理，保留原因和操作记录，并校验身份冲突、作答、批次和材料引用。本轮不新增身份校正页面，不绕过同卷限次或改写历史作答快照。

### 回收站与恢复

- “删除试卷”执行归档并移入回收站，填写原因，保留固定身份、材料、正式批次、编辑记录及学生历史。
- 归档前展示关联数据和执行影响。正在处理或发布的任务须先停止或完成；归档与最终激活须互斥，不能出现后台任务在归档后重新开放试卷。
- 归档后停止学生新的访问与作答入口。已被服务端接收的提交按原有状态完成或查询；仅在本地的未提交草稿保留，归档期间禁止新提交，恢复后按原批次和版本重新校验。
- 恢复保留同卷身份、历史作答次数和旧结果；不自动恢复学生可见。管理员须对当前有效批次重新确认开放。
- 学生查看本人历史仍按原有历史访问权限执行；不得借回收站或历史记录扩大音频和答案访问权限。

## 五 人工编辑技能与错因

### 编辑能力

| 对象 | 必需能力 |
| --- | --- |
| 技能 | 新增、删除、替换技能编码；设置 PRIMARY 或 AUXILIARY；编辑理由和证据 |
| 错因 | 按错误基准选项新增、删除、替换编码；编辑机制说明、证据和个人核验要求 |
| 干扰项评估 | 维护状态、比较理由、比较证据和未决点，结果覆盖三个错误选项 |
| 证据 | 从本篇有效原文选择句子或单句内连续引文，编辑支持说明并试听 |
| 对照 | 同时查看 AI 原始候选、人工变更及最终结果，支持逐项差异查看 |

### 保存和送审约束

1. 完整结果每题恰好一个主要技能；辅助技能须有独立必要性。只能使用启用且适用于题目标注的词典编码。
2. 每条技能与错因均须有合法原文证据，答案证据单独维护。多句引文按连续有序正文全文拼接，单句可以引用连续子串；不得跨篇、引用提问或编造引文。
3. 错因绑定同题的具体错误基准选项，正确答案禁止挂错因。重复身份为“题目＋基准选项＋错因编码”，不能合并不同选项，也不能丢掉同一机制的独立证据。
4. 每个错误选项允许零个或多个有依据的错因，不设置数量配额；标签描述潜在误选机制，不能诊断学生已经发生该错误。
5. `SUPPORTED` 须有至少一条有依据候选且无未决点；`NO_SUPPORTED_CANDIDATE` 须为空候选、明确比较理由且无未决点；`INSUFFICIENT_EVIDENCE` 须保留未决点并阻断通过。
6. 删除某选项最后一条错因时，要求填写材料比较理由或明确改为依据不足；不能自动把删除结果当成已审核合法空标注。
7. 可暂存尚不完整的人工编辑草稿，须显式标记缺项；不能生成“结构通过”或“审核通过”的有效结果。非法编码、越权、错误归属和引用不存在对象等错误应直接拒绝。
8. 保存有效内容变更须填写修改原因并形成版本。相同内容的重复提交保持幂等，不生成重复版本；保存不触发 AI 调用。

### 原始候选与人工修订

最终内容由“冻结来源＋AI 原始候选（如有）＋人工修订记录”确定性重建。每条人工修订包含目标题目、字段或关系、前值、后值、理由、证据、操作人、时间及父版本哈希。

保留模型原始响应和调用回执记录，不把人工改值写回模型原始产物。纯人工结果标记人工来源，不能要求或补造模型 receipt。审核、缓存、恢复和入库校验均须支持真实的 AI、人工及混合来源，核对最终结果哈希及修订链，而非继续要求所有最终字段等于模型原始响应。

### 重新生成与人工修改的取舍

- 局部重生成、更换模型或选择其他评测结果时，新结果作为独立候选保存，展示与当前人工结果的差异，不自动覆盖当前草稿中的人工修改。
- 管理员显式选择采纳范围，保留旧候选、原人工修改和采纳记录；未选择采纳的内容不被静默替换。只重生成错因时，不自动覆盖范围外的人工主要技能等内容。
- 采纳前检查当前版本、来源、选项、词典及证据依赖。依赖失效的人工修改须标记并处理，不能机械叠加到新候选；存在关联约束时，提示必须一并处理的内容。
- 采纳有效内容变更须填写原因并生成新的保存版本，整套最终审核重新进行。仅生成或查看候选不等于采纳、发布或开放。

## 六 修改记录与版本保留

### 版本生成与差异

- 一次明确保存形成一个版本，不按按键、光标变化或只读访问生成版本。可用的临时自动保存不替代正式版本记录。
- 版本快照覆盖内容、技能、错因、三项评估、证据、选项映射，以及原文、音频、对齐和词典依赖。关联材料可按哈希引用，无需复制音频文件。
- 记录版本号、父版本、保存人、服务端时间、修改原因、来源类型、前后哈希和差异；区分人工保存、模型生成、来源校正及历史回退。
- 支持查看版本及与当前版本的差异，明确新增、删除、替换、证据变化和状态变化。

### 保留规则

“上一版本永久”的业务含义为：紧邻最新保存版本的上一份快照始终受长期保护；当它不再是上一版本时，再开始七天保留期，不是每一份曾经的上一版本都无条件永久保存。

| 记录 | 保留方式 |
| --- | --- |
| 最新保存版本 | 长期保护 |
| 紧邻的上一保存版本 | 长期保护，不受七天清理影响 |
| 更早且无其他保护的恢复快照 | 从退出上一版本保护的服务端时间起至少保留 7×24 小时 |
| 当前正式批次及被业务引用的历史版本 | 保留，直至相关依赖允许清理；不能仅按时间删除 |
| 必需审计记录、审核依据、AI 原始调用与费用账本 | 按既有追溯规则保留，不纳入七天快照清理 |

例如 V4 为最新版本时，V4、V3 受保护；保存 V5 后，V5、V4 受保护，V3 从此刻计算七天。超过七天仅表示符合候选清理条件，不能越过引用保护。

最新保存版本、上一版本的保护在各试卷的有效修订历史中确定；不能通过另建分支清空旧修订仍需保留的业务引用。当前正式批次独立受保护，不因编辑版本前进而被误清理。

### 清理与记录查看

- 清理前检查当前和上一版本、正式批次、学生作答、历史快照、审核、重处理、模型来源和回退依赖。尚在执行、审核或发布的版本不得清理。
- 若版本以增量保存，清理父快照前必须保留完整恢复链或转为独立快照，不能造成受保护版本无法重建。
- 只清理已无保护的恢复快照或可重建副本，不改写不可变原始证据。被其他版本引用的共享材料和对象不能连带删除。
- 清理执行时重新核对引用，与保存、回退和发布并发时采用版本校验，记录清理时间和结果。失败重试不重复破坏数据。
- 页面显示保护原因、七天期限和可恢复状态。快照过期后仍显示修改摘要及清理记录，不能显示可回退按钮；摘要不能冒充完整可恢复内容。

## 七 回退标注与内容

1. 支持选择历史版本，查看拟恢复内容与当前内容的差异，并填写回退原因。
2. 支持恢复整套编辑快照，或选择某题内容、技能、错因及证据。局部恢复必须一并检查关联依赖，不能机械拼接不兼容的标签、答案和原文。
3. 执行回退前检查快照存在、权限、当前版本、材料、词典、选项及对齐依赖。历史词典已停用的编码允许查看，不能未经当前规则检查直接发布。
4. 回退生成一个新的保存版本和待审修订，记录来源版本及所选范围；不覆盖旧历史，也不直接切换正式批次。恢复本身不调用模型；确需重新对齐或标注时显式列出范围。
5. 来源相同且依赖有效时可以复用核听与来源记录；任一内容或标签变更仍重新完成整套最终审核。
6. 正式生效继续走入库、激活与独立开放。回退失败、依赖失效或快照过期时保留当前版本和正式批次，返回明确原因。

## 八 两家官方 AI API

### 配置与使用

| 用途 | 官方服务 | 模型 |
| --- | --- | --- |
| 默认标注 | DeepSeek 官方 API | `deepseek-flash` |
| 替代标注 | 阿里云百炼官方 API | `qwen3.8-flash` |

管理员在任务开始前选择模型。进行中的任务固定供应商与参数；切换模型创建新标注修订，并重新审核新结果。失败不静默切换供应商或思考模式。

密钥只保存在受控服务端配置，不进入页面响应、源代码、文档或日志。任务详情只展示供应商、模型、阶段、用量和费用摘要。具体地域与端点在部署配置中明确，不使用来源不明的中转服务。

### 统一输入与校验

- 保留 V7 的三个干扰项评估、恰好一个主要技能及严格来源校验。统一题目、来源答案、原文分句、词典、业务规则和提示词。
- 供应商适配器处理请求协议、支持参数、输出提取、完成状态、拒绝、限流及用量统计，返回统一内部结果，并保留可验证的原始请求与响应。
- 本地完整 Schema 为最终结构标准；发送给供应商的兼容 Schema 可按实际能力调整。记录两者版本或哈希，不能为兼容接口放宽本地业务校验。
- 记录供应商、官方端点标识、请求模型、响应模型、可取得的实际模型版本、提示词、词典、Schema、适配器版本和实际参数。模型别名无法固定服务端权重时如实记录，不声称完全可复现。
- 拒绝、空输出、截断、非法 JSON 和校验失败分别记录；保留原有有限纠错机制，每次收费调用单独记账。结构或来源纠错不能靠删除失败候选或清空结果通过。

### 费用与恢复

- 供应商、模型、币种、价格版本、缓存及思考用量分别记录。统一预算口径时记录换算依据，不能沿用 DeepSeek 单价计算千问费用。
- 沿用已有预算约束与未知计费处理；取消小样不等于取消单套和累计预算。新流程不再误受前 5 题阶段门控，历史小样账目继续累计。
- 预留应覆盖该供应商的最大可能输出及适用计费项目；提高输出上限时同时调整预留，不能只放大请求参数。
- 未确认扣款按预留计入预算，已知用量估算须明确为估算，不能标成供应商实际扣费。显式重试不抹去旧记录或重复收费保护。
- 断点续跑按相同输入、模型、规则和依赖验证已有结果，跨模型不能直接复用候选或审核结论。

## 九 一套题的模型相同率对比

### 样本与执行

首轮固定 2025 年 6 月 CET4 第 1 套，共 25 题、75 个错误选项。使用同一份经来源审核与核听确认的冻结内容、原文分句、基准选项、词典与业务提示词，分别由两个模型独立生成整套。

本轮不设置 5 题试标停点，也不把另一模型标签或人工修改后的结果加入对方输入。供应商专用格式包装和实际参数如实记录。保存原始生成与纠错后结果；相同率主报告使用通过校验的最终模型候选，并附首次通过率、纠错次数和失败情况。

### 相同率定义

| 指标 | 定义 |
| --- | --- |
| 主要技能相同率 | 两模型主要技能编码相同的题数 ÷ 25 |
| 完整技能相同率 | 技能编码与 PRIMARY／AUXILIARY 角色集合完全相同的题数 ÷ 25 |
| 错因相同率 | 两模型错因编码集合完全相同的错误基准选项数 ÷ 75 |
| 非空错因相同率 | 在至少一方有合法非空错因集合的选项中，两方合法集合完全相同的比例 |

- 标签按“题目身份＋基准选项”对齐，集合顺序不影响相同判定；多一个或少一个编码均算不相同。非法重复关系先按校验错误处理，不靠集合化掩盖错误。
- 双方均为完整、合法的 `NO_SUPPORTED_CANDIDATE` 时，空集合可以算相同。失败、漏标、`INSUFFICIENT_EVIDENCE` 或无完整生成记录均不能按空集合算相同，整体分母仍为 25 或 75。
- 非空选项分母为零时报告“不适用”，不能报告 100%；同时列出不完整选项数，不能只报非空指标掩盖失败。
- 理由文字、引文长度与时间不进入标签相同率，但仍执行全部来源校验；三个干扰项状态另列一致情况。
- 人工修改后的结果单独留存，不参与模型原始相同率。分歧项进行人工核对，记录各方理由与最终意见；相同率不等于准确率。

### 交付结果

输出整体指标，以及逐题、逐错误选项的编码对照、差异、评估状态、校验情况、纠错次数、模型版本、费用和耗时。正文同时列分子与分母，例如 24/25，而非只报百分比。

本轮先形成这一套题的实测结论，不预设或承诺相同率阈值，也不据一套题宣称对所有材料等效。默认模型维持 DeepSeek，是否调整另依据实测分歧和成本决定。

允许在有限纠错后仍有失败项时完成对比报告交付和报告验收，不以全部 25 题均生成合法结果作为报告验收的前提。须逐题、逐选项列明失败、缺失、依据不足及因预算或前置失败未执行的范围，附已有调用、纠错及费用记录，整体指标仍使用 25 或 75 的固定分母；未执行内容不能冒充真实生成结果。报告须明确完成范围和结论限制，不因允许失败而无限重试、追加预算或使用人工结果补齐模型相同率。报告通过不表示对应试卷可以入库，正式入库仍须满足全部内容、结构、来源与审核门控。

## 十 页面与操作一致性

- 所有入口位于现有题库管理、处理详情和审核区域，沿用现有导航和权限。编辑、保存、送审、入库、开放分开操作并明确显示结果。
- 查询与试听不保存内容、不调用模型。离开未保存编辑时提示；修改已保存但未生效时明确显示待审状态。
- 重要变更展示影响范围，包括需重做的核听、标注和整套审核；保存、回退和重生成不默认执行后续收费步骤。
- 多管理员或多标签页修改使用版本号或哈希校验，过期保存返回冲突并允许查看最新差异，不静默覆盖。
- 处理与发布期间阻止不兼容的修改、归档和回退，或先明确停止任务。已撤销执行权的 Worker 不得继续写入、调用模型或激活批次。
- 归档、恢复、回退、保存、重试和发布支持幂等，页面重复点击不生成重复版本、任务或正式批次。
