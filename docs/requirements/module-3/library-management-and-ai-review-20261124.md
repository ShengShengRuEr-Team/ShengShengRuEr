## 二 需求文档问题检查

### 1. 激活与独立开放之间的访问行为冲突

V1.0 主流程规定先激活新批次，再独立开放；LIB-37 同时要求新版本尚未开放时原有效批次保持可用。现有单一当前批次机制无法同时满足这两种行为。

代码依据：[激活逻辑](../../../backend/app/services/processing/tasks.py)、[学生访问条件](../../../backend/app/repositories/listening.py)。现有激活逻辑取消旧批次的当前状态，将新批次设为当前且默认不可见；学生访问又要求当前批次检查通过并已开放。因此新批次激活后、开放前，该卷暂时不可访问。

处理结果：沿用现有机制，接受暂时不可访问，分别验收激活前旧卷可用和激活后新卷待开放。保留旧批次及作答历史不等于继续允许学生读取旧卷。

### 2. 人工修改与重新生成缺少取舍规则

V1.0 规定保留人工修订，也支持局部重生成及切换模型，但未说明新候选如何与已有人工修改合并，存在覆盖人工成果或保留失效关系的风险。

处理结果：新生成结果独立保存；展示与当前人工结果的差异，由管理员选择采纳范围。保留候选、人工修改及采纳历史，依赖失效的修改不能直接叠加；采纳有效变更后整套最终审核重置。

### 3. 非标准练习卷及身份校正的交付边界不明确

V1.0 提及非标准练习卷及专门身份校正，但缺少相应完整规则和验收范围，容易在实施时扩展为新卷型、新判分规则或独立管理页面。

处理结果：本轮仅支持四级、六级标准完整真题；非标准练习卷另立需求。身份校正沿用受控后台处理，不新增管理页面。

### 4. 当前草稿与独立评测结果的关系不明确

V1.0 说明按试卷有效修订历史保护最新与上一版本，但未明确同卷能否有多份并行编辑草稿，也未区分双模型结果与当前编辑内容。

处理结果：同卷只有一个当前可编辑草稿；历史修订及双模型评测结果独立保留，选定候选后才进入当前编辑修订。保存版本、模型结果版本与运行检查点的具体生成边界仍需开发设计明确。

### 5. 模型对比报告的完成条件不明确

V1.0 已规定固定整体分母、合法空集合及失败不得按空集合计算，但未说明存在最终失败项时是否允许验收报告。

处理结果：允许验收如实披露失败及未执行范围的报告，整体分母仍为 25 或 75；报告验收与正式入库分别判断。局部字段合法、其他字段失败时的统计有效性粒度，仍需在统计设计中明确。

## 四 开发设计补充项

以下属于开发人员需要形成具体设计和验证方案的事项，不表示增加新的业务审批，也不改变已确认规则。

| 编号 | 补充项 | 需要明确的内容 |
| --- | --- | --- |
| DEV-01 | 预算归集 | 沿用单套 2 美元、阶段累计 5 美元的既有上限及未知费用预留规则；明确双供应商、修订、重试及历史调用的归集范围、币种换算和预算键，不能因切换供应商自动增加额度 |
| DEV-02 | 旧任务过渡 | 已停在独立核听或五题试标阶段的任务如何继续、迁移或保留旧流程；保存原始记录，不补造批准，不把新流程门控错误套到旧记录上 |
| DEV-03 | 依赖失效表 | 修改题干、答案、选项、原文、说话人、音频、分句及搜索范围，分别影响哪些标注、对齐、证据、核听和最终审核；明确受影响范围及复用条件 |
| DEV-04 | 版本生成边界 | 区分明确保存的编辑版本、独立模型结果和逐题运行检查点；明确当前草稿版本链、最新与上一版本保护，以及候选采纳和回退如何进入保存历史 |
| DEV-05 | 相同率有效性粒度 | 某题部分内容合法、其他内容校验失败时，各指标是否可计入相同分子；明确失败与未执行的呈现，以及非空指标分母的计算，保持整体分母 25 或 75 不变 |
| DEV-06 | 方法配置冻结 | 按官方能力明确地域、端点、思考模式、输出上限、超时、并发和有限纠错参数；保留原有约束，不能因接入第二家供应商静默放宽 |
| DEV-07 | 当前规则同步 | 实施时同步项目 AGENTS.md 及技术说明中仍按旧流程描述的内容；历史需求和验收记录保留日期及适用范围，不追溯改写历史结论 |

其中 DEV-01 是既有预算在双供应商场景下的落实要求，不是新预算授权。若实际运行证明确需超过既有上限，应先提交具体费用及影响说明，再由用户决定是否调整。

## 五 已明确且无需重复询问的要求

- 核听并入来源审核，标注前必须完成真实核听及来源确认；取消前五题试标停点。
- 默认 DeepSeek 官方 `deepseek-flash`，替代为阿里云百炼官方 `qwen3.8-flash`；实际能力和参数在接入时按官方文档核对。
- 人工修改、模型原始候选和调用记录分开留存，不能伪造模型响应或把人工值写回原始响应。
- 任一题内容、标注或证据变化后，整套最终审核重新完成；依赖有效的来源和核听记录可以复用。
- 保存、回退、生成候选和报告验收均不自动发布或开放；学生错因隔离、同卷限次和历史作答快照继续有效。
- 最新保存版本与紧邻上一保存版本受长期保护；更早且无其他保护的快照从退出上一版本保护时起至少保留七天。
- 相同率不等于准确率；不设置本轮相同率阈值，不以一套题证明所有材料等效。
