# 模块一范围说明

本页从仓库现有说明与已实现接口归纳，供文档导航使用；未取得独立原始需求文件，不声称这是补签的需求定版。

- 账号登录、退出、当前用户信息、管理员与学生身份区分及基础接口鉴权。
- 前端提供登录、管理端首页、学生端首页、403 页面及路由守卫。
- 后端沿用 PostgreSQL、SQLAlchemy 与 Alembic，退出失效写入数据库。
- 未登录或登录失效返回 401；学生请求管理员接口返回 403。
- 模块一不包含作答判分、错题本与个性化推荐。

实现及运行说明见 [后端](../../../backend/README.md) 和 [前端](../../../frontend/README.md)；模块一接口回归入口为 `backend/scripts/acceptance.py`。历史执行结果不自动适用于后续修改。
