### 1.3 术语

| 术语 | 含义 |
|---|---|
| 一次作答（attempt） | 学生对一套试卷完成一次提交形成的记录，含逐题作答与判分结论；每次提交一条，互不覆盖 |
| 整卷 | 一套试卷当前批次下的全部题目，题号以模块二"原卷题号"为准 |
| **学生可访问** | 当前批次 ∧ 内容检查通过 ∧ 管理员确认可见；本文只用该词组表示合取，准入复用模块二既有判定 |
| 管理员确认可见 | 仅指三个条件中的第三个，不得指代合取 |
| 查询时准入 | 结果能否读取，以每次**读取时**的状态判定，不锁定提交时状态 |
| 判分快照 | 提交瞬间固化的判分结论与结果内容，此后不随题库变化 |
| 练习估分 | 按官方题型占比折算的 0–249 分结果，**非官方成绩**；题型缺失或非 25 题标准卷时不输出；与正确率分开呈现 |
| 题目身份 | 既有学生详情已返回的题目唯一标识；用于校验提交内容与当前批次是否同一版本（EX-09b），不新增向学生暴露的内部 ID |
| 提交键 | 标识"同一次提交"的可识别信息，用于识别重试；形式留开发文档 |
| 解析 | 题目文字讲解，受保护内容，交卷前不下发；"无解析"指空串或仅空白，不指 NULL |
| 听力正文 | 听力原文/转写文本。**不返回正文片段、原文时间轴与全文；解析文本同样不得包含正文原文**（整句、整段均不允许）；自动校验与判定规则见 T11 |
| 未作答 | 交卷时该题未选中任何选项 |

### 1.5 与既有约束的关系（约束例外声明）

模块二需求（B04.3/B05）确立：学生接口只返回学生可见字段，不返回答案、解析、原文；不先返回再隐藏；不提供含上述内容的原始资料下载。本轮例外：

1. **唯一例外**：新增"交卷后结果读取"能力。读取条件（查询时判定）：本人 ∧ attempt 已提交 ∧ 读取当时该试卷仍"学生可访问"。
2. 现有学生接口不因交卷改变，不新增"已交卷则返回答案"分支。
3. 不新增含答案、解析、听力正文的导出或下载能力；现有音频接口保持只读音频。
4. **生效条件**：本例外是对模块二 B04.3/B05 的定向修订，自负责人书面签认并同步回写模块二需求之日起生效；未签认前按原约束执行，即本轮不实现结果读取能力，并纳入 R5 签认包。**P6（题库内容治理）未满足时同样不生效**。
5. 回归项：交卷前后读取整卷详情，均不得出现答案、解析、正文。
6. **解析引用正文的边界见 D10（12.2）**：现行口径为**禁止**（1.3 / BR-08）。**允许范围**：D10 未拍板前不得引用；若拍板"允许有限引用"，须同时定义可判定上限（单句/连续词数）并并入本条与 B04.3/B05 回写。**违规处理**：属题库内容层拦截——含正文原文的解析视为该题内容不合格，不得进入可访问试卷，由内容核对/检查把关，**不属作答系统职责**。**所属模块**：题库内容治理（模块二检查、模块三核对）；**检测算法与阈值留开发文档（T11）**，不得作为放行标准。

### 3.2 用户与前置条件

- **学生**：唯一可作答与读取结果的角色。
- **管理员**：不得代替学生作答（403）；不可读取学生结果（403，R1）。理由：`api.md:76` 允许管理员调用学生视角详情，返回的是题库内容；作答结果属个人数据。

### 7.2 判分快照字段集（2-6 闭合）

快照为**整份结果**。逐项断言：

| # | 快照项 | 断言 |

### 7.3 状态与状态机

attempt 只有一个持久状态，无草稿、修改、删除态（D6）：

```
无记录（未提交）
  ├─ 提交且准入通过 → 已提交（终态，只读）
  ├─ 提交且准入拒绝（AS-07） → 幂等标记（不产生 attempt）
  └─ 提交且内容版本不一致（EX-09b） → 幂等标记（不产生 attempt）
```

| 状态 | 含义 | 迁移 |
|---|---|---|
| 无记录 | 未提交 | →已提交（新键成功）；→幂等标记（准入拒绝或版本拒绝） |
| 已提交 | 判分完成并落库，只读 | 无 |
| 幂等标记 | 该键被**准入拒绝或内容版本不一致**拒绝 | 同键→同一拒绝结论；换键→新提交 |

不做：草稿态、作答中态、超时作废态、重判态。"重新作答"=新键+新 attempt。

### 7.4 四维与 attempt 关系

| 维度 | 归属 | 与 attempt 关系 |
|---|---|---|
| 当前批次 | 模块二 | 提交时记录标识；读取不锁定 |
| 内容检查 | 模块二 | 提交与读取都须通过 |
| 管理员确认可见 | 模块二 | 取消期间不可读 |
| 标注审核/模块三验收 | 后续模块 | 不参与准入 |

attempt 状态与四维互不合并，不新增"完成"类聚合状态。

### 7.5 业务约束

| 编号 | 约束 |
|---|---|
| DC-1 | 一次成功提交一条 attempt，不可拆分或合并 |
| DC-2 | 逐题事实条数=题目总数，不缺不多 |
| DC-3 | 同一学生+同一提交键至多一条成功 attempt；发生**准入拒绝或内容版本不一致**的键之后不得成功（参数非法/服务端错误不在此列） |
