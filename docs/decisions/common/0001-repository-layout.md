# 0001：单仓库与模块目录

- 日期：2026-10-30
- 状态：已采纳（本次仓库初始化）

## 背景

项目由多人协作，后续计划上线。前端、后端与 AI 能力需要一起调整接口和验证，当前远端只有 README，尚无已确定的应用技术栈。

## 决定

使用一个 GitHub 仓库，一级目录固定为 `frontend/`、`backend/`、`ai/`、`docs/`、`deploy/`、`scripts/`。

保留仓库名称 `ShengShengRuEr`，技术标识使用 `shengshengruer`。Git 分支采用 `main`、`develop` 和任务、发布、热修复分支；规范分别记录在命名与 Git 工作流文档中。

目录初始化不等同于技术选型。先建立文档和协作入口，不预置框架应用、虚构依赖、数据库或独立 AI 服务。各模块确认技术栈后，补充可运行入口与实际验证方法。

## 影响

前后端接口和 AI 行为可以在一个 PR 内协同更新。模块之间仍需明确边界，不能把单仓库理解为任意跨目录依赖。

未来只有在独立发布、权限或维护规模形成明确需求时，才讨论拆分仓库；不要提前承担跨仓库联调成本。
