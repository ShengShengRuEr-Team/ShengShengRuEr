# 0002：模块一前端技术栈

- 日期：2026-10-31
- 状态：已采纳（模块一前端脚手架）
- 关联：[frontend/README.md](../../frontend/README.md)；版本与页面依据《模块一开发文档 v0.2》第 5 章（外部工作目录，未入库）

## 背景

模块一需要 7 个页面（登录、管理端试卷 / 题目 / 任务、学生端试卷 / 题目、403），学生团队 2 人，页面规模小、无复杂状态。后端 9 个接口与响应外壳已定，前端需要与后端角色 / 权限码严格对齐。

版本来自 npm registry 实测（2026-10-31），并已在本机完成安装与构建验证。

## 决定

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 构建 | vite **8.3.5** + @vitejs/plugin-react **5.2.0** | plugin-react 5.2.0 已声明支持 `vite ^8`，且只有一个 peer（vite）；6.x 额外要求多条 Rolldown / oxc 管线 peer，一期不承担 |
| UI 组件库 | antd **6.6.8** | 后台类表格 / 表单 / 菜单组件最全，peer 要求 `react >= 18`，与 React 19 兼容 |
| 图标 | @ant-design/icons **6.3.4** | 与 antd 6 同系列 |
| 路由 | react-router-dom **7.18.5** | 静态路由表 + 组件级守卫，比数据路由更易讲清、易验收 |
| 语言 | typescript **6.0.3** | 不使用 7.x（原生重写版本，生态风险） |
| 状态 | React Context（`AuthProvider`） | 全局只有登录态与 permissions，引状态库过重 |
| 请求 | axios **1.21.0** 实例 + 双拦截器 | 统一注入 Bearer、统一处理 401 / 403 |
| token 存储 | `localStorage`，key `ssre_access_token` | 刷新不掉登录；XSS 风险用「不渲染不可信 HTML」缓解 |
| 开发端口 | 5173，`strictPort: true` | 后端 CORS 只放行 `localhost:5173` / `127.0.0.1:5173`，换端口即跨域失败 |
| 接口地址 | 直连 `http://127.0.0.1:8000`，不用 Vite proxy | 后端 CORS 已按 5173 配置；直连与接口约定「基础地址 127.0.0.1:8000」一致，少一层代理歧义 |
| 代码质量 | 本期不引入 ESLint / Prettier | 版本未锁定；7 个页面的门禁用 `tsc -b` + `vite build` 足够，后续再补 |
| 路径别名 | 本期不配 `@/` | 配别名需要新增未锁定的 `@types/node`；页面层级浅，相对路径可接受 |

`package.json` 直接依赖全部精确版本，禁止 `^` / `~`；传递依赖由 `package-lock.json` 锁定并随代码提交。

## 后果与影响

- **版本升级需手工进行**：改 `package.json` 精确版本 + 重新生成锁文件 + 复跑构建，不能靠 `npm update` 漂移。
- **端口与 CORS 强耦合**：改开发端口必须同步改后端 `allow_origins`，否则所有请求跨域失败。
- **antd 全量引入使单 chunk 约 570 kB（gzip 184 kB）**：一期可接受，页面增多后按路由做 `import()` 拆分。
- **token 存 localStorage 有 XSS 暴露面**：一期以「不渲染不可信 HTML」缓解，CSP 列入后续。
- **身份判定权在后端**：前端守卫只负责体验（隐藏菜单、跳 `/403`），越权最终由后端 403 兜底，不能把前端判断当安全边界。
- **TS 6 / vite 8 属于较新版本线**：如遇工具链问题，先定位再决定是否调整，不在功能 PR 中混入版本回退。
