# API 契约

当前尚无已实现或冻结的业务接口。以下只约定协作方式，实际 API 由具体需求确定。

跨模块功能先在此明确接口，再由前后端分别开发。文档按业务域组织，例如 `listening-exercises.md`、`attempts.md`、`recommendations.md`。

每个接口说明：

1. 场景、方法与路径。
2. 登录要求和资源访问权限。
3. 路径参数、查询参数、请求结构与字段约束。
4. 成功响应和非敏感样例。
5. 失败状态、错误结构与边界情况。
6. 关联需求、实现状态和兼容性变化。

API 使用 `/api/v1` 前缀，路径资源用复数 `kebab-case`，JSON 和参数字段用 `snake_case`。响应外壳、分页和错误码尚未决定，不在各模块中自行采用不同方案。

选定框架后，以可版本管理的 OpenAPI 契约或与实现同步的接口定义作为权威来源，本目录保留业务语义与使用说明。
