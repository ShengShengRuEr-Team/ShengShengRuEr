## 与首验报告的关系

`frontend-acceptance-20261109.md`（首验报告）引用的 19 张 `01_*.png`…`19_*.png` 由验收人在其受控目录生成，**未随报告入库**，因此按该报告的相对路径打开会 404。本目录不复制他人的取证截图；如需归档，请把验收人目录整体拷贝到 `screenshots/first-acceptance/`，再修改报告路径。

本目录的 `shot_*` 是开发者自查与复验证据，文件名与首验报告不同，二者不可互相替代。
