## PR #25 独立验收反馈整改

对应以 `e5571af` 为对象的 2026-11-23 验收反馈。本节记录修复后的开发复验。

| 问题 | 改动和证据 |
| --- | --- |
| P1 列表快照字段 | 从列表、状态更新移除题干及所选字母。门禁关闭时，列表和状态更新仍只返回元数据，详情返回 503。门禁开启后，原作答只在获准的详情展示。 |
| P2 隐藏记录入口 | 已隐藏记录显示「已隐藏，恢复后可查看详情」。「已隐藏」和「全部」里的隐藏项只提供恢复操作，恢复后按权限查看。隐藏详情的服务端拒绝由 API 测试覆盖。 |
| P3 标注审核时间 | 端到端 API 测试将详情的 `annotation_reviewed_at` 与已通过审核会话的提交时间直接比对。无可展示标注时为 `null`。组件验证有时间时显示、无时间时省略。 |
| P4–P5 接口对齐 | V0.2 需求、开发文档从 PR #23 同步。三个 JSON 示例、接口路径和每页上限 50 与运行中的 OpenAPI 核对通过。 |

补测 WB-AC02 时，以回环代理延迟服务端已成功提交的响应，客户端实际发生读取超时。
用原幂等键直接重试后取得同一个 `attempt_code`，错题数保持两条。补测 WB-AC09
时在同来源批次更正题干和解析，历史详情与更正前一致。

Chromium 实跑 1280×720 和 1440×900。覆盖交卷、隐藏及全部筛选、恢复、批准详情展示
原交卷选项、历史解析受限和音频换批。

Python 3.13.16 与 PostgreSQL 18.6 隔离库的 `python -m scripts.verify_module3 --suite api`
返回 `PASS_TECHNICAL`，502 项通过、14 项跳过。`npm test -- --maxWorkers=2`
的 139 项测试通过，`npm run build` 成功。独立复验与正式放行签认待团队记录。
