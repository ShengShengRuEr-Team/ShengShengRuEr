# PR #21 错题本整改自测

本记录使用隔离数据库和合成试卷，供非作者复验。正式环境开启状态写入及受保护详情分别
需要 WB-D02、WB-D05 所要求的放行依据。复验时可在隔离环境单独打开两个开关，
配置和回退影响见[错题本 API](../../development/wrong-answers/api.md)。

| 验收条目 | 开发复验 |
| --- | --- |
| WB-AC01～AC03 错题归集和查询 | 答错和未作答进入本人列表，正确作答排除。覆盖分页、试卷、作答类型、复习状态及隐藏筛选。记录从已提交作答快照派生。 |
| WB-AC04～AC05 原交卷快照和详情门禁 | 验证默认详情返回 503。隔离环境放行后验证正确选项和解析来自原交卷快照，响应不含听力原文。 |
| WB-AC06～AC07 候选错因和技能 | 合成已审核标注验证了原卷 A → 题库 B 的选项映射，及学生字段白名单。 |
| WB-AC08 复习状态、隐藏和恢复 | 验证默认关闭写接口。隔离环境开启后可标记已掌握、重新标记待复习、隐藏和恢复。重复操作与隐藏恢复均保留原提交成绩，恢复保留隐藏前复习状态。 |
| WB-AC09～AC10 换批、下线及账号边界 | 验证换批后快照仍为旧提交，音频沿用模块二当前卷绑定。试卷下线后列表与总数排除该卷，详情、状态更新和受控音频拒绝访问。 |
| WB-AC11 双分辨率 | Chromium 在两种视口验证入口、快照详情、标记已掌握、隐藏、恢复及恢复后状态保留。 |
| WB-AC12 既有模块回归 | 在 `backend/` 执行 `python -m scripts.verify_module3 --suite api`，结果为 PASS_TECHNICAL，耗时 225 秒，500 项通过、14 项跳过。前端 `npm test` 通过 136 项，`npm run build` 通过。 |
| WB-AC13 迁移 | PostgreSQL 18.6 独立库完成 0011 → 0012 → 0011 → 0012。旧移出记录保留为已隐藏，作答与判分快照逐行比对一致。降级会丢失复习状态及时间。 |
| WB-AC14 独立验收 | 待非作者在 GitHub 留下评审与独立验收记录。 |
